# PyChess

PyChess est un jeu d'échecs développé en Python utilisant les bibliothèques `python-chess` pour le moteur de jeu et `pygame` pour l'interface graphique.

## Fonctionnalités prévues

1. **Moteur de jeu** : Gestion des règles d'échecs et des mouvements des pièces avec `python-chess`.
2. **Interface graphique** : Affichage du plateau et des pièces avec `pygame`.
3. **Bot IA** : Un bot simple basé sur l'algorithme Minimax avec une évaluation de position. (Not Yet)

## Installation

1. Clonez ce dépôt :
   ```bash
   git clone <url-du-repo>
   ```
2. Installez les dépendances :
   ```bash
   pip install -r requirements.txt
   ```

## Lancement

Exécutez le fichier principal pour démarrer le jeu :
```bash
python main.py
```
